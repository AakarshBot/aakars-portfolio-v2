# Aakarsh Portfolio V2

A new portfolio for Aakarsh Bommakanti, built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment

The project is designed for Vercel. Import the GitHub repository into Vercel and deploy with the default Next.js settings.
